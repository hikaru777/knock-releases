# ノック（Knock）

Mac の画面の端で、友達とつながるアプリです。

- ダウンロード：[最新版の Knock.zip](https://github.com/hikaru777/knock-releases/releases/latest/download/Knock.zip)
- 紹介ページ：https://hikaru777.github.io/knock-site/
- 動作環境：macOS 26 以降（Apple シリコン / Intel）

このリポジトリは配布用です。各版の zip（Apple の公証済み）と、アプリが新しい版を確かめるための `appcast.xml` を [Releases](https://github.com/hikaru777/knock-releases/releases) に置いています。ソースコードはここにはありません。
